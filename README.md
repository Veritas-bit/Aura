# AURA 0.0.1

Элегантная панель инструментов для Windows в стиле Dynamic Island. Персонаж
временно отключён — готовится новая версия с 3D-моделью.

## Запуск

Требуется .NET SDK 10.

```powershell
cd DynamicIsland
dotnet run -c Release
```

Для сборки автономного приложения запустите `build.bat` из папки `DynamicIsland`.

Подробнее о возможностях и управлении: [DynamicIsland/README.md](DynamicIsland/README.md).
