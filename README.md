# AURA

Лаунчер-компаньон для Windows в стиле Dynamic Island: часы, системный статус,
погода и панель с приложениями и инструментами.

## Запуск

Требуется .NET SDK 10.

```powershell
cd DynamicIsland
dotnet run -c Release
```

Для сборки автономного приложения запустите `build.bat` из папки `DynamicIsland`.

Подробнее о возможностях и управлении: [DynamicIsland/README.md](DynamicIsland/README.md).
